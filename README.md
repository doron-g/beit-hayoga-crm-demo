# בית היוגה — מערכת ניהול לידים ומשימות (CRM)

מערכת CRM מותאמת אישית ל**בית היוגה (House of Yoga — מקום שמחבר)** לניהול לידים, משימות ואוטומציות מעבר בין עמודות לפי זמן.

## ✨ פיצ'רים עיקריים במערכת
- **🗂️ הלידים שלי (Kanban & List View):** לוח קנבן עם גרירה ושחרור (Drag & Drop), סינון וחיפוש מהיר, כרטיס ליד מפורט (Drawer) ותיעוד שיחות והערות.
- **➕ ניהול והרחבת סטטוסים (עמודות):** הוספת עמודות חדשות ללוח באופן חופשי (למשל `"לאחר שבוע"`), בחירת צבע, שינוי סדר והצגה/הסתרה בלוח.
- **⚡ אוטומציות מעבר עמודות מבוססות זמן:** הגדרת חוקים שמעבירים ליד אוטומטית מעמודה לעמודה אחרי פרק זמן מוגדר (שבועות / ימים / שעות / דקות / שניות), כולל כפתורי **סימולציית זמן (`+1 יום` / `+7 ימים`)** לבדיקה מיידית בהדגמה.
- **📋 המשימות שלי:** ניהול פעילויות ומשימות לפי `היום`, `מחר`, `אתמול`, `טווח תאריכים` ו`לא בוצעו`, בסנכרון דו-כיווני מלא עם כרטיסי הלידים.
